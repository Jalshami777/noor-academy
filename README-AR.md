# Noor Academy — تطبيق المنصة

هذه الحزمة تحتوي على نسخة الويب المحسّنة من المنصة وتهيئة جاهزة لتغليفها كتطبيق Android باستخدام Capacitor.

## ما تم تحسينه
- حفظ اختيار العربية/English محلياً، مع ضبط `lang` و`dir` تلقائياً (RTL للعربية وLTR للإنجليزية).
- واجهة المنصة الأصلية تحتوي على 413 استدعاء ترجمة ثنائي اللغة بصيغة عربية/إنجليزية، وتم الإبقاء على النصوص ومحتوى المنصة الأصلي.
- أزرار واجهة الاجتماع التجريبية أصبحت تغيّر حالة التفعيل بصرياً بدلاً من الاكتفاء برسالة عامة.
- إضافة PWA manifest وService Worker وأيقونة، وإظهار زر التثبيت عندما يدعم المتصفح ذلك.
- إضافة طبقة سجلات محلية تحفظ التفضيلات والجلسات والمفضلة والرسائل والاشتراكات التجريبية على الجهاز عند عدم وجود خادم.
- جميع أزرار HTML الأصلية الـ75 لها معالجات نقر في التطبيق المصدر.

## تشغيل نسخة الويب محلياً
يتطلب Node.js 20 أو أحدث:

```bash
npm install
npm start
```

ثم افتح `http://localhost:4173`.

## إنشاء تطبيق Android (APK)
1. ثبّت Android Studio وAndroid SDK وJDK 17.
2. من مجلد المشروع نفّذ:

```bash
npm install
npx cap add android
npx cap sync android
npx cap open android
```

3. داخل Android Studio اختر **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. ملف APK التجريبي يظهر عادةً في:
   `android/app/build/outputs/apk/debug/app-debug.apk`

أو بعد إنشاء مجلد android، على Linux/macOS:

```bash
npm run android:build
```

## تنبيه مهم قبل النشر
- وضع الدفع في هذه الحزمة تجريبي ومحلي؛ لا يتم خصم أموال حقيقية ولا توجد بوابات دفع مصرفية متصلة. لا تفعّل وضع Live قبل الحصول على بيانات تاجر رسمية وربطها بخادم آمن وWebhook والتحقق من الدفع من جهة الخادم.
- اجتماعات Zoom المعروضة واجهة تجريبية؛ تشغيل اجتماعات حقيقية يتطلب Zoom Meeting SDK وخادم OAuth/Token آمن. لا تضع Client Secret أو مفاتيح الدفع داخل التطبيق.
- طبقة التخزين المحلية مناسبة للعرض والاختبار على جهاز واحد، وليست بديلاً عن قاعدة بيانات وخادم إنتاجي أو نظام حسابات آمن متعدد المستخدمين.
- قبل النشر على Google Play، أضف سياسة خصوصية، شروط الاستخدام، إعدادات التوقيع، وأيقونات PNG بأحجام متجر Play، واختبر الأجهزة وإصدارات Android المستهدفة.
- لم يتم إنشاء APK موقّع هنا؛ الحزمة جاهزة لفتح مشروع Android وإنشاء APK من Android Studio بعد تثبيت الأدوات المذكورة.
